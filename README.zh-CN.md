## 项目简介

**项目主题：The Hidden Costs of Living in Toronto**

本项目旨在研究多伦多不同社区的收入水平、住房情况、住房经济负担和公共交通通勤方式之间的关系。

我们小组将通过四个独立的研究问题，分析不同社区的生活条件，并以社区家庭收入中位数作为共同的分析主线，整合研究结果。

## 数据集

**Toronto Neighbourhoods Dataset (STA130 Fall 2026)**

- **数据来源：** [STA130 GitHub Repository](https://github.com/skyepaphora/STA130-FA26/tree/main/Project)
- **数据文件：** `toronto_neighbourhoods_STA130.csv`
- **数据规模：** 158 个社区，80 个变量
- **分析工具：** R、tidyverse、ggplot2、Quarto

## 小组研究问题

### Q1：收入与租房比例

在多伦多，家庭收入中位数较低的社区，租房住户所占比例是否更高？这种关系在多伦多四个不同区域之间是否存在差异？

### Q2：租房负担能力

在多伦多各社区中，月租金中位数越高，住房支出占收入至少 30% 的租房家庭比例是否也越高？这种关系是否会随着获得租金补贴的租房家庭比例而有所不同？

### Q3：住房条件与维修需求

在多伦多，老旧住房比例越高的社区，需要重大维修的住宅比例是否也越高？这种关系是否会随着社区中 Condominium（共管产权住宅）所占比例的变化而有所不同？

### Q4：收入与公共交通通勤

在多伦多不同社区中，家庭收入中位数与公共交通通勤比例之间存在怎样的关系？这种关系在以高层住宅为主的社区和其他社区之间是否有所不同？
